# Task sets

| Set | What it is | Provenance / license |
| --- | --- | --- |
| `basic/` | ten small shell / Python / C tasks with deterministic checks | written for this project, Apache-2.0 |
| `polyglot-py/` | 35 Python exercises, each with a prompt, starting files, a reference solution and a verifier | derived from Exercism exercises as packaged by the Aider "polyglot" benchmark. Exercism's code and problem descriptions are published under the MIT license; some exercises carry extra attribution in their metadata. **Maintainer to-do before the public release: confirm the license of every directory here and add per-exercise attribution where the source asks for it.** If any exercise cannot be redistributed, replace this directory with a script that fetches it. |

Sets generated from private repositories or archives (`user-*`, `workbuddy-code/`) are never committed; `.gitignore` excludes them.
