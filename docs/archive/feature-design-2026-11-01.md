# 功能设计

本文档描述产品"做什么、怎么表现、遵守什么规则"。系统组成见 `architecture.md`,CairnSandbox 自我改进机制见 `aios-rsi.md`,已定的取舍见 `decisions.md`。

---

## 0. 产品定位与对象关系

**一句话**:一个让你在隔离沙箱里运行 agent,并在可信评测下让 agent 的运行内核(CairnSandbox)自我改进的平台,支持云端与本地两种站点。(架构 v0.2 见 `architecture.md`;其中第 5 节的"任务内循环"是本文第 2 节工作台尚未写入的新功能:参考执行、两个候选、fork 探测、采纳、改进库。)

核心对象:

```
用户 ─┬─ 沙箱(多个) ─── 任务 ─── 事件(轨迹)
      │       └─ 快照 / fork
      ├─ 任务集 ─── 任务定义(含验收脚本)
      ├─ 实验 ─── 候选(CairnSandbox 版本)─── 评测结果
      │               └─ 版本树(稳定 / 候选 / 淘汰)
      └─ 治理:审批、网络策略、审计、预算
```

关键关系:
- 每个沙箱属于一个**项目**。项目是数据的归属范围:长期记忆、产物库、任务集和实验都挂在项目下;沙箱之间共享数据只能经过项目级存储。详见 `data-and-storage.md`。
- 沙箱运行**某个 CairnSandbox 版本**。新建沙箱默认用"当前稳定版"。
- 实验产出候选版本;候选通过晋升后才能成为稳定版。
- 评测在沙箱之外进行;任务集的验收脚本和隐藏测试从不进入沙箱。

## 1. 账号、配额与设置

| 项 | 规则 |
|---|---|
| 账号 | 个人账号,邮箱或第三方登录;暂不做团队与角色 |
| 配额 | 沙箱数量上限、单沙箱 CPU/内存/磁盘上限、并发实验数、并发评测沙箱上限、每日模型成本上限 |
| 超额行为 | 拒绝新建并说明原因与当前用量;**不终止**正在运行的沙箱或任务 |
| 模型接入 | 用户可配置模型服务与密钥;密钥加密保存在控制面,沙箱内拿不到 |
| 设置项 | 默认网络策略、默认资源规格、空闲自动暂停时长、通知渠道、审批策略 |

## 2. 工作台

### 2.1 沙箱列表

**展示**:名称、状态、类型(持久型/临时型)、站点(云端/本地)、模板、CairnSandbox 版本、资源规格、空闲时长、累计成本、创建时间。实验自动创建的临时型评测沙箱默认折叠在对应实验下,不混入工作台列表。

**操作**:打开、暂停、恢复、快照、fork、重命名、删除、升级 CairnSandbox 版本。

**状态**:

| 状态 | 含义 |
|---|---|
| 创建中 | 正在分配与初始化 |
| 运行中 | 可交互 |
| 已暂停 | 进程已停止,文件保留 |
| 失败 | 创建失败或节点故障,显示原因,可重试恢复或删除 |
| 已删除 | 不可恢复 |

转换:创建中→运行中;运行中⇄已暂停;任意状态→失败;运行中/已暂停/失败→已删除。

**规则**:
- 空闲超过设定时长自动暂停(默认 30 分钟,以"无终端输入、无任务运行"为空闲)。
- 暂停超过保留期(默认 7 天)前先通知,到期后删除;删除前可导出。
- 筛选:按状态、站点、模板、CairnSandbox 版本、标签。

### 2.2 创建沙箱

| 选项 | 说明 |
|---|---|
| 模板 | 预置环境(语言工具链、常用软件),有版本号 |
| CairnSandbox 版本 | 默认当前稳定版;可选历史稳定版或某个候选版本(候选版本沙箱带"实验性"标记) |
| 资源规格 | 小/中/大三档预设,可自定义但受配额限制 |
| 网络策略 | 断网(默认)、包管理镜像预设、自定义白名单;放宽策略可能触发审批 |
| 初始内容 | 空、上传文件、从 Git 仓库克隆、从快照 |
| 类型 | 持久型(默认,工作台使用)或临时型(一次性,用完即弃,不做定期同步,不支持暂停) |
| 生命周期 | 空闲暂停时长、最长存活 |

**过程**:显示进度(分配、拉取镜像、启动、daemon 就绪、CairnSandbox 就绪);失败给出具体原因(配额、资源不足、镜像拉取失败)。

### 2.3 对话与任务

**概念**:用户给 agent 一个目标就是一个**任务**;任务运行期间的补充说明是**插话**,在 agent 的下一步边界生效。

**任务状态**:

| 状态 | 说明 |
|---|---|
| 排队 | 沙箱已有活动任务,等待 |
| 运行中 | agent 正在执行 |
| 等待审批 | agent 申请超出当前权限的能力,等待用户 |
| 等待输入 | agent 向用户提问(澄清/确认) |
| 成功 / 失败 | 正常结束,失败附原因 |
| 已取消 | 用户取消,保存检查点 |
| 超预算 | 触发预算上限,保存检查点,可追加预算后继续 |
| 已中断 | 沙箱暂停或节点故障,恢复后可从检查点继续 |

**规则**:
- 一个沙箱同一时刻只有一个活动任务,其余排队;要并行就开多个沙箱。
- 创建任务时可设置预算(模型成本、时间、步数),默认取用户设置。
- 输出流式显示:消息、工具调用与结果、命令输出、文件改动。
- 用户可随时中断、取消、插话、追加预算。
- 任务结束给出摘要:做了什么、改了哪些文件、成本、耗时、验收结果(如有)。

### 2.4 终端与文件

| 功能 | 规则 |
|---|---|
| 终端 | 多标签,基于 PTY;用户与 agent 共用同一文件系统与环境;用户终端的操作同样写入审计 |
| 文件浏览 | 目录树、搜索、预览;支持上传、下载(单文件和压缩目录)、重命名、删除 |
| 文件编辑 | 内置简易编辑器 |
| 变更提示 | agent 修改了用户正在编辑的文件时提示冲突,保存时让用户选择合并、覆盖或另存 |
| 限制 | 单文件上传大小、总磁盘配额、命令输出大小上限(超出截断并提示) |

### 2.5 轨迹回放

- 以时间线展示全部事件:消息、工具调用、命令及输出、文件改动、状态变化、预算变化。
- 可按任务、类型、关键词过滤;可跳到任意步骤;文件改动可查看 diff。
- 从某一步骤"在此分叉":当该步骤附近有检查点时,从最近检查点 fork 出新沙箱;没有则提示不可用。
- 可导出为结构化文件(用于复现与分析)。

### 2.6 暂停、快照、fork

| 操作 | 行为 |
|---|---|
| 暂停 | 停止沙箱内全部进程,文件保留;**正在运行的进程不会保留**,恢复时需重新启动(界面明确提示) |
| 恢复 | 重新启动沙箱,CairnSandbox 从最近检查点恢复任务上下文 |
| 快照 | 保存当前文件系统状态,命名并可附说明;数量受配额限制 |
| fork | 从当前状态或某个快照创建新沙箱,继承文件和 CairnSandbox 版本,**不继承运行中的进程和对话以外的运行状态**;fork 出来的沙箱独立计费与计量 |

### 2.7 多沙箱规则

- 沙箱之间默认**网络隔离**,不能互相访问。
- 需要传递内容时通过"导出/导入产物":从沙箱 A 选文件导出,导入沙箱 B,是显式复制,全程记审计。
- 列表页可批量暂停、批量删除、按标签分组。

## 3. 实验(自我改进)

### 3.1 任务集

**任务定义**:

| 字段 | 说明 |
|---|---|
| 标识与描述 | 给 agent 的目标文本 |
| 领域标签 | 如编码、命令行运维、文档与数据处理、长程任务 |
| 初始环境 | 模板 + 初始文件/仓库提交 |
| 限制 | 时限、预算 |
| 验收 | 验收脚本,**保存在评测器一侧**,输入为沙箱最终文件系统导出,输出为通过与否或 0 到 1 的得分及诊断 |
| 参考解 | 可选,用于校验任务质量 |
| 分组 | 演化集 / 留出集 / 隐藏集(一个任务只属于一组) |

**任务质量检查**(导入时自动运行;依据见 `rsi-algorithms-survey.md` 2.7、6.7):
- 参考解必须能通过验收;
- 空解、no-op agent、空输出与穷举输出必须不通过;
- 同一解重复验收 3 次结果一致;
- 运行时长在限制之内;
- 初始环境镜像里不得含测试、参考解、.git 历史或其他答案载体;
- 指令与测试一致性由模型审一遍并人工确认;
- 记录来源/集群标签,切分演化集、验证集、测试集时按来源切,防止同源泄漏。

**任务区分力**:历史通过率恒为 0 或 1 的任务对版本比较没有信息,标记为"无区分力",不进入比较核心集,只保留在回归检查中。

不合格的任务标记并暂不参与评测。

**管理**:任务集有版本号,修改产生新版本;实验引用具体版本,保证可复现。

### 3.2 基线与噪声

- 对某个 CairnSandbox 版本在指定任务集上每任务重复运行 K 次(默认 5,可调),保留"任务 × 次"的结果矩阵,输出每任务通过率、整体 avg@K、任务内方差、置信区间、成本。
- **噪声带 δ**:把 K 次结果按半分法反复分成两组,两组整体分之差的 95% 分位即 δ;候选相对父代的提升必须超过 δ 才算进步。版本比较一律做**同任务配对**(配对差的标准误、二元指标用 McNemar、分级指标用配对 bootstrap),不要用非配对方差。
- 不用温度 0 "降噪":文献实测它不消除噪声且引入偏差;记录模型版本、端点与缓存命中率,任一变化即重测基线。
- 基础设施失败(沙箱起不来、代理故障)单独标记并重试至多 3 次,不计入任务失败。
- 基线结果按(CairnSandbox 版本哈希、任务集版本、模型版本)缓存,任一变化则失效。
- 基线是实验的前置步骤:没有基线不能创建实验。

### 3.3 创建实验

| 配置 | 说明 |
|---|---|
| 目标 | 要改进的范围:R1(提示词、技能、记忆与上下文策略)或 R2(可变服务实现代码)。R2 需要先通过隔离与门槛检查 |
| 起点 | 选定的父代版本(默认当前稳定版) |
| 父代选择策略 | 最优优先、按新颖度、手动指定 |
| 每轮编辑预算 | 单个候选最多允许的改动量,随轮次递减 |
| 评测集 | 选择演化集、留出集;隐藏集不参与 |
| 预算 | 总成本、总时间、迭代数、并发候选数 |
| 并发评测沙箱上限 | 同时存在的评测沙箱数量上限,超出的排队;由调度器节流,避免突发创建 |
| 停止条件 | 达到目标提升、预算耗尽、连续若干轮无提升、用户终止 |
| 审批策略 | 哪些改动类型需要人工审批(默认:新增工具/系统调用、放宽网络、读用户数据、架构变更) |

### 3.4 运行视图

- 总览:当前迭代、已评测候选数、当前最佳、累计成本曲线、预计剩余。
- 候选队列,每个候选的阶段:提议中、构建中、契约检查、系统性质检查、演化集评测、留出集评测、待审批、已入库、已淘汰。
- 操作:暂停、继续、终止、调整预算。
- 异常提示:作弊指标升高、评测失败率上升、成本超预期。

### 3.5 候选详情

- 改动摘要(agent 给出的理由)与完整 diff(代码、配置、提示词)。
- 批评者(critic)结论:是否疑似只针对具体任务。
- 契约检查、系统性质检查结果(通过或失败项)。
- 演化集与留出集得分:均值、置信区间、与父代的差、逐任务对比。
- 作弊指标与成本。
- 链接到对应评测轨迹。

### 3.6 版本树

- 节点是 CairnSandbox 版本,边是父子关系;颜色区分稳定、候选、淘汰;标出当前稳定版。
- 点击查看详情;任选两个版本对比 diff 和得分。
- 支持沿某条谱系查看累计改动和得分变化。
- 档案库保留多样的中间版本,不只保留最优;可手动标记"保留"或"清理"。

### 3.7 晋升与回滚

**级联评测**(省成本,见 `rsi-algorithms-survey.md` 6.4):烟测(3 到 5 个最简单任务,失败即淘汰,其余题计 0)→ 演化集核心任务每任务 K 次(默认 3)→ 仅对位列档案库前二的候选跑演化集全集(K = 5)与留出集。

**自动晋升条件**(全部满足):
1. 契约检查与系统性质检查全部通过;
2. 演化集配对提升超过噪声带 δ,且配对置信区间下界为正;噪声带内的候选不晋升,但可按成本与新颖性进入档案库;
3. 留出集不低于父代,且提升的置信区间下界为正或不显著劣化(按配置);
3a. 成本增量满足 ΔC ≤ β0 + β1·ΔS(默认不允许用数倍成本换几个百分点);
4. 旧任务不退步;
5. 无作弊指标告警;
6. 改动类型不在需审批列表中,或审批已通过。

**晋升动作**:将版本标为"稳定",成为新建沙箱的默认版本;**已有沙箱不被自动升级**,用户在列表里手动升级。

**回滚**:一键将"当前稳定版"指回已知良好版本或任一历史稳定版;回滚不影响正在运行的沙箱;回滚记录审计。

晋升与回滚由沙箱之外的晋升控制器执行,只接受评测器签名的结果。

### 3.8 隐藏集揭示

- 隐藏集不参与任何自动选择,仅用于阶段性评估。
- 查看需要显式"揭示"操作并记录次数,界面显示累计揭示次数,提醒不要把它当作调参集。
- 对 agent 始终不可见。

### 3.9 成本与报告

- 面板:每轮成本、每分提升成本、噪声水平、各改动类型(调度/上下文/记忆/工具)的历史成功率。
- 实验报告导出:配置、版本谱系、各版本得分与置信区间、成本、CairnSandbox 版本哈希、模型版本、任务集版本、随机种子,保证可复现。

## 4. 治理

### 4.1 审批中心

| 审批项 | 触发 | 默认策略 |
|---|---|---|
| 放宽网络 | 候选或任务要求新增可访问域名 | 需审批 |
| 新增工具或系统调用 | 候选改动涉及 ABI 或工具注册 | 需审批 |
| 读取用户数据 | 请求访问用户导入的数据或本地文件夹 | 需审批 |
| 架构变更(R3) | 新增、拆分、合并服务 | 需审批 |
| 晋升为稳定版 | 自动条件满足但被配置为需人工确认 | 可配置 |
| 追加预算 | 任务或实验超预算 | 需确认 |

**审批卡片**:改动或请求的内容、风险等级、影响范围、agent 的说明、证据(评测结果、相关轨迹)。
**操作**:批准、拒绝、要求修改并附说明。
**规则**:超时未处理按拒绝处理;审批人与时间写入审计。

### 4.2 网络策略

- 三种预设:断网、包管理镜像、自定义白名单。
- 可按沙箱或按实验设置。
- 放宽需审批,收紧立即生效。
- 出站请求记录(目标、时间、大小),可查询;被拒绝的请求单独记录。

### 4.3 审计

- 记录:命令、文件改动、网络请求、模型调用、审批、晋升与回滚、配置变更、用户登录与操作。
- 只追加,沙箱内无法修改或删除。
- 查询:按沙箱、任务、实验、时间、事件类型、用户;支持导出。
- 敏感事件高亮,如尝试访问 daemon 的 socket、修改测试或评测文件。

### 4.4 异常与作弊监测

**监测项**:读取或列举测试目录、任务目录之外的敏感路径;修改验收相关文件、测试、计时函数;访问 .git 历史;尝试访问内核或 daemon socket、提权;异常网络访问;输出异常膨胀;重复相同动作循环;硬编码特判(验收脚本带变体输入检出);分数高于该任务历史分布 2σ 的运行自动进入人工复核队列;"演化集超父代但留出集否决"的比例作为过拟合指标。任务集中放少量"规格与测试冲突"的不可能任务作为探针,通过即记作弊。
**处理**:计入候选的"作弊指标";超阈值时标记候选、暂停实验并通知;指标和得分一起展示。

### 4.5 成本上限与熔断

- 三级:用户(每日/每月)、实验、沙箱或任务。
- 达到 80% 提醒,达到 100% 停止相应对象并保存检查点。
- 成本由沙箱之外的模型代理和资源计量得出,不采信沙箱内自报。

### 4.6 密钥与凭证

- 用户的模型密钥只存控制面;沙箱使用短期、可撤销、限额的令牌,经代理调用模型。
- 沙箱内不保存长期凭证;需要访问用户的外部服务(如 Git)时,走单独的、限定范围的短期凭证并需审批。

## 5. 桌面端与本地模式

| 功能 | 规则 |
|---|---|
| 本地站点 | 桌面端启动本地节点代理,本地沙箱与云端沙箱出现在同一个列表,以站点标记区分 |
| 工作文件夹 | 用户选定一个文件夹,只读或写时复制方式挂入本地沙箱;未选定的位置不可见 |
| 差异审阅 | agent 对工作文件夹的修改先落在叠加层;任务结束或用户请求时展示差异,**确认后才应用到真实文件**;可逐文件、逐块接受或拒绝 |
| 需确认的动作 | 删除工作文件夹外内容、联网安装、执行有外部副作用的命令、读取工作文件夹外的数据 |
| 网络 | 默认断网,按任务白名单 |
| 版本 | 本地只运行云端已晋升并签名的 CairnSandbox 版本;不做自我改进实验 |
| 模型调用 | 经桌面端代理;无网络时不能运行任务,只能浏览历史 |
| 日志 | 本地全量记录,联网后同步审计 |
| 与云端协作 | 可把本地沙箱的产物导出到云端沙箱,或把云端结果下载到本地,均为显式操作 |

## 6. CairnSandbox 的功能规格(agent 侧)

CairnSandbox 是 agent 的运行内核,也是被自我改进的对象。分为**不可变内核**(特权分离的薄层)与**可变服务**。

### 6.1 系统调用接口(ABI)

agent 与可变服务通过版本化的接口访问内核能力。能力清单:

| 类别 | 能力 |
|---|---|
| 执行 | 运行命令、读写文件、搜索文件 |
| 网络 | 发起受策略限制的请求 |
| 交互 | 向用户提问或请求确认 |
| 任务 | 创建子任务、等待结果、取消 |
| 记忆 | 读写记忆条目 |
| 状态 | 创建检查点、恢复检查点 |
| 预算 | 查询当前用量与剩余(只读) |
| 事件 | 写入事件 |

ABI 带版本号,向后兼容;变更需人工评审。

### 6.2 调度

- 一个任务可以拆成子任务,在同一沙箱内并发执行,默认并发上限为 3。
- 优先级:用户交互 > 前台任务 > 后台任务。
- 公平:同级轮转,避免饥饿。
- 抢占:高优先级可在步边界暂停低优先级。
- 保护:检测重复相同动作循环,超过阈值则打断并上报;子任务有独立超时。

### 6.3 上下文管理

- 上下文预算划分:系统提示与工具定义、记忆检索结果、历史、工具输出。
- 压缩策略:工具输出保留头尾并截断中间;历史滚动摘要;被截断或摘要的原文落盘,可通过引用取回。
- 触发:占用超过阈值(默认 70%)时压缩。
- 检查点中保存摘要和引用,保证恢复后上下文可重建。
- 压缩策略属于可变服务,可被自我改进。

### 6.4 记忆

| 层级 | 范围 | 说明 |
|---|---|---|
| 工作记忆 | 单个任务 | 即当前上下文 |
| 会话记忆 | 单个沙箱 | 以文件形式保存的笔记、计划、待办 |
| 长期记忆 | 跨任务 | 默认按沙箱隔离;用户可选择与同项目沙箱共享 |

规则:
- 条目带来源引用和时间;由 agent 写入。
- 检索:关键词,可选语义检索。
- 遗忘:过期、低使用率、用户删除。
- **用户可查看、编辑、删除全部记忆**。
- 评测沙箱使用空记忆或固定的记忆快照,保证不同候选之间可比。
- 记忆内容是数据,不属于 CairnSandbox 版本;记忆管理策略属于可变服务。

### 6.5 工具管理

- 内置工具:执行命令、文件读写与编辑、搜索、受限的网络获取、向用户提问、创建子任务、记忆读写。
- 每个工具声明:所需能力、是否幂等、副作用等级、超时。
- 调用带唯一标识;已完成的调用恢复时返回记录结果,不重复执行。
- 失败处理:可重试的按退避重试,不可重试的上报给 agent。
- 工具选择与编排策略属于可变服务。

### 6.6 能力与权限

- 任务启动时,能力 = 用户策略 ∩ 该 CairnSandbox 版本声明的需求 ∩ 沙箱网络策略。
- 子任务只能继承父任务能力的子集,能力只能收缩不能放大。
- 申请超出当前能力的操作时,任务进入"等待审批"。
- 安全上限(成本、网络、资源、审计)由沙箱之外强制,内核内的检查只负责语义与提示。

### 6.7 预算

- 任务级:模型成本、时间、步数、工具调用次数、输出字节数。
- 用量达到 80% 产生告警事件,达到 100% 停止并保存检查点。
- agent 可以只读查询剩余预算,用于调整策略;无法修改预算。

### 6.8 检查点与恢复

- 自动检查点:任务边界,以及每 N 步(默认 10)。
- 内容:任务目标、计划与待办、已完成步骤、上下文摘要与引用、文件系统快照引用。
- 恢复:从最近检查点继续;对非幂等工具调用,恢复后先让 agent 核对实际状态,不盲目重放。

### 6.9 事件与可观测性

- 事件类型:消息、工具调用、工具结果、命令输出、文件改动、状态变化、预算变化、审批、错误。
- 每个事件带序号、时间、任务标识;断线重连后可从某序号继续。
- 指标:步数、token、延迟、工具成功率、压缩次数、重复动作次数。

## 7. 通知

| 事件 | 默认渠道 |
|---|---|
| 任务完成、失败、超预算 | 站内 + 桌面通知 |
| 等待审批、等待输入 | 站内 + 桌面通知 |
| 成本达到 80% 与 100% | 站内 + 桌面通知 |
| 实验结束、候选通过门槛、被淘汰 | 站内 |
| 异常与作弊告警 | 站内 + 桌面通知 + 邮件(可选) |
| 沙箱即将因保留期到期被删除 | 站内 + 邮件(可选) |

用户可按事件类型开关渠道。

## 8. 跨功能规则

### 8.1 故障与恢复

| 情形 | 行为 |
|---|---|
| 节点故障 | 该节点上的沙箱标为"失败";磁盘尚在则可恢复为"已暂停";任务标为"已中断" |
| 模型服务失败 | 按退避重试;持续失败则任务进入"已中断",保留检查点 |
| daemon 失联 | 标为失败并尝试重连;超时后保留磁盘 |
| 磁盘写满 | 阻止写入并提示,不终止沙箱 |
| 评测器不可用 | 实验暂停,不做任何晋升决策 |
| 输出无限增长 | 按大小上限截断,标记异常事件 |

### 8.2 并发与一致性

- 用户与 agent 同时修改同一文件:见 2.4 的变更提示。
- 请求幂等:创建沙箱、提交任务等带客户端请求标识,重复请求返回同一结果。
- 断线重连:客户端从上次事件序号继续订阅,不丢事件。

### 8.3 可复现

每次评测和实验记录:CairnSandbox 版本哈希、模板版本、任务集版本、模型版本、随机种子、预算,保证结果可复核。

## 9. 范围边界(不做的功能)

- 桌面 GUI 环境(computer-use)与图形化沙箱。
- 团队协作、角色权限、组织级管理。
- 计费与结算。
- 沙箱之间的网络直连。
- 离线运行 agent。
- 模型微调与权重训练。
- 自动化的架构变更(R3)、对 ABI 与评测器的任何自动修改。
- 面向公众的开放注册。
